Question: How can a linear predictor be updated on new information while retaining its predictions on a fixed set of old examples?
Old feature matrix X in R^{n x d}; parameter w in R^d; old prediction vector Xw. A candidate update u in R^d comes from an unspecified learning step, whose derivation is outside this passage.
Idealized update: choose an orthonormal basis N in R^{d x r} of ker(X), project u to v=NN^T u, set w'=w+v. Then Xw'=Xw exactly. N has zero columns if the null space is zero-dimensional, and the update is zero. The elementary proof is XN=0; the contribution here is an explanatory setup, not a claimed new theorem. Projection may remove the direction needed to learn the new task; this property provides no guarantee of new-task improvement or generalization to other old examples.
Implementation uses the orthogonal projector P_epsilon onto the right-singular subspace whose singular values are <= epsilon, including the exact null space; epsilon>0. Put v_epsilon=P_epsilon u. This can include directions with nonzero singular values, so exact retention need not hold. In exact arithmetic, the SVD implies ||XP_epsilon||_2 <= epsilon, hence ||X(w+v_epsilon)-Xw||_2 <= epsilon ||u||_2. These are Euclidean norms and spectral operator norm; dimensions and epsilon are explicit. Actual floating-point numerical error has not been separately bounded.
Use this optional simple illustration if helpful: X = diag(1, 0.01), w=(2,3), u=(1,4), epsilon=0.02. X has trivial exact null space, so the idealized update is zero. The thresholded projector retains only the second coordinate, giving v_epsilon=(0,4). The prediction shift is (0,0.04). Do not describe these numbers as experimental evidence; they are an exact arithmetic illustration.
