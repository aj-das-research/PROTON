\begin{abstract}
Retrieval checking improves supported answers but calling a checker every time costs resources. We introduce \ourmethod{}, which uses a confidence score to call a verifier. On 600 held-out questions, it obtains 72.0\% accuracy versus 72.3\% for always checking, with 0.42 versus 1.00 verifier calls per question. This proves that our method is superior and highly efficient for all retrieval systems.
\end{abstract}
