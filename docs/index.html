PROTON+: contamination-robust prototype banks for test-time online OOD detection with medical VLMs

Abhijit Das1, Nichula Wasalathilaka2, Yifan Lu1, Adinath Dukre1, Dwarikanath Mahapatra3, Shadab Khan4, Imran Razzak1,5

1MBZUAI   2University of Peradeniya   3Khalifa University   4ADIA Lab   5MedOS

▶ Live browser demo (real FLAIR weights) Code (official implementation) PROTON+ preprint (PDF) All tables PROTON (arXiv)

PROTON+ is the follow-up to our PROTON paper, and this repository is the official implementation of both. PROTON+ is the recommended method; the original algorithm stays available as the default configuration for comparison.

TL;DR

PROTON adds an online, per-class prototype bank on top of a frozen medical vision-language model (VLM) so that covariate-shifted inputs (new devices, new populations) that look confident to the softmax can still be flagged by their position in embedding space. We reproduce PROTON from scratch on three modalities (FLAIR / UniMed-CLIP / QuiltNet) and find that its confidence gate admits exactly the confidently-misclassified OOD samples it should exclude, so the prototypes get contaminated and the method can fall below plain MCM. PROTON+ fixes this with domain-anchored prototypes (a mean-shift step that locks each class prototype onto the dominant imaging domain of the bank), a consistency gate for bank admission, and scale-free fusion. Same cost, no training, no prompt engineering, no labels.

Method in one picture

Plain-text summary of the computation
stream x_t ─► frozen VLM ─► e_t (embedding), p_t = softmax(e_t·T/τ)
                              │
                              ├─ S_base(t)  = −max p_t                (MCM, or any logit/softmax score)
                              ├─ S_proto(t) = 1 − max_c ⟨e_t, μ_c⟩     (μ_c: online class prototypes)
                              └─ score(t)   = α_t · z(S_base) + (1−α_t) · z(S_proto)
bank update (after scoring):  admit e_t to class ĉ if max p_t ≥ γ  AND  (PROTON+) ‖e_t − μ_ĉ‖ typical of admitted samples
PROTON+ prototypes:           μ_dom = mean-shift mode of all bank members;  μ_c ∝ Σ_i exp((⟨e_i, μ_dom⟩−1)/h) e_i

Headline numbers

AUROC (%) per shift type, mean over 5 stream orders. PROTON+ beats MCM on every covariate and far stream on all five orders in all three modalities; it trails MCM on the ophthalmology semantic shift, which the preprint discusses. Full tables with AUPR/FPR@95, ablations, ID-fraction sweeps and prompt sensitivity are on the results page.

Use it on your own data

pip install -e ".[models,data,plots]"
proton make-benchmark --name mydata --vlm flair --id normal=/d/id/normal --id "diabetic retinopathy=/d/id/dr" \
    --ood semantic=/d/glaucoma --ood covariate=/d/uwf --ood far=/d/natural --prompt "A fundus photograph of {}"
proton extract --benchmark mydata && proton run --benchmark mydata      # every table in outputs/results/mydata/

Any open_clip checkpoint works as the VLM (--vlm open_clip:hf-hub:org/name); a new model is a four-method subclass of proton.models.base.VLM.

Reproduce

git clone https://github.com/aj-das-research/PROTON && cd PROTON
pip install -e ".[models,data,plots]" && tools/fetch_third_party.sh && pip install -e third_party/FLAIR
tools/download_data.sh && tools/download_weights.sh
proton prepare-data && proton extract --benchmark ophthalmology && proton run --benchmark ophthalmology && proton figures
